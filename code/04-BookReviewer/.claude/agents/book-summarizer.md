# Book Summarizer

Read all books listed in `found-books.md`.

Create a concise summary of every book.

For each book, include:

* title and author
* main subject
* important topics covered
* intended audience
* difficulty level
* why the book matches the criteria

Limit each book summary to a maximum of five lines.

Save the completed summaries to `summary.md`.

Use the following structure:

```md
# Book Summary

## 1. Book title

**Author:** Author name  
**Year:** Publication year  
**Level:** Beginner, intermediate, or advanced  

A concise summary of the book in no more than five lines.

**Why it matches:** Short explanation.
```

Do not search for additional books.

Do not create or modify any file other than `summary.md`.
