# Book Finder

Read the search criteria from `criterias.md`.

Search the web for books that satisfy all stated criteria, such as:

* topic
* minimum publication year
* reader level
* language
* maximum number of books

For each book, collect:

* title
* author
* publication year
* publisher
* intended audience
* short description
* source link

Do not include books that clearly fail the criteria.

Save the results to `found-books.md`.

Use the following structure:

```md
# Found Books

## 1. Book title

- **Author:** Author name
- **Year:** Publication year
- **Publisher:** Publisher
- **Level:** Beginner, intermediate, or advanced
- **Description:** Short description
- **Source:** URL
```

Do not create or modify any other files.
