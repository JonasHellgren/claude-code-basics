# Book Notes

## 1. Reinforcement Learning Explained: A Practical Problem-Solving Approach

**Author(s):** Jonas Hellgren, Johannes Lindgren
**Year:** 2026
**Level:** Beginner

A practical, problem-solving introduction to reinforcement learning aimed at readers without a coding or university-level math background. It explains how RL agents learn optimal behavior through interaction and reward feedback, illustrated with many small, focused examples. Application areas covered include robotics, energy systems, finance, and autonomous vehicles.

**Why it matches:** Beginner-friendly, requires no prior technical background, and uses hands-on, practical examples to build intuition step by step.

## 2. An Introduction to Deep Reinforcement Learning

**Author(s):** Vinod K. Mishra
**Year:** 2025
**Level:** Beginner

An introductory text on deep reinforcement learning (DRL) written for undergraduate and early graduate students new to the field. It reviews basic machine learning concepts before covering the mathematical and algorithmic foundations of DRL, including single-agent and multi-agent algorithms, recent developments, and real-world applications.

**Why it matches:** Positioned as a starting point for newcomers, balancing accessible introductions with the mathematical grounding needed to progress into deeper study.

## 3. Mathematical Foundations of Reinforcement Learning

**Author(s):** Shiyu Zhao
**Year:** 2025
**Level:** Beginner

A mathematically grounded but approachable introduction to reinforcement learning, requiring no prior RL background. It covers foundational concepts (Bellman equations, stochastic approximation) and classic algorithms (value/policy iteration, Monte Carlo methods, temporal-difference learning, value function approximation, policy gradient, and actor-critic methods), using a recurring grid-world example throughout.

**Why it matches:** Introduces RL from first principles with a consistent example, making rigorous mathematical content accessible to beginners.
