**Journal/Conference:** IEEE Transactions on Dependable and Secure Computing

## Abstract / Summary
MCP enables AI agents to seamlessly connect with external tools but introduces vulnerabilities such as Tool Poisoning Attacks (TPA), where hidden malicious instructions exploit LLM sycophancy to manipulate agent behavior. The paper presents MCPXKIT, categorizing and implementing 31 distinct attack methods across four classifications (direct tool injection, indirect tool injection, malicious user attacks, and LLM inherent attacks), with quantitative efficacy analysis.

## Key Contributions
- A comprehensive MCP attack taxonomy (31 attack methods, 4 classifications).
- MCPXKIT: a unified, executable attack framework for MCP security analysis.
- Empirical vulnerability analysis revealing agents' blind reliance on tool descriptions, file-based attack sensitivity, and chain attacks via shared context.
- Foundational framework supporting secure evolution of MCP ecosystems.
