## Abstract / Summary
A systematic study of MCP from both architectural and security perspectives. The paper defines the full lifecycle of an MCP server across four phases (creation, deployment, operation, maintenance) decomposed into 16 key activities. Building on this lifecycle analysis, it constructs a comprehensive threat taxonomy covering four attacker types (malicious developers, external attackers, malicious users, security flaws) across 16 distinct threat scenarios, validated through real-world case studies.

## Key Contributions
- Full MCP server lifecycle model (4 phases, 16 activities).
- Comprehensive threat taxonomy across four attacker categories and 16 threat scenarios.
- Real-world case studies demonstrating concrete attack surfaces.
- Fine-grained, actionable security safeguards mapped to lifecycle phase and threat category.
- Landscape analysis of industry adoption, integration patterns, and tooling; future research directions on standardization and trust boundaries.
