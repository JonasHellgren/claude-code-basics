# Beyond the Protocol: Unveiling Attack Vectors in the Model Context Protocol (MCP) Ecosystem

**Authors:** Hao Song et al.
**Publication year:** 2025
**Journal/Conference:** IEEE Transactions on Software Engineering
**DOI/URL:** https://consensus.app/papers/details/a36cd4168ffd59fcb4ad4c4ed78e225c/?utm_source=claude_desktop
**Citations:** 13

## Abstract / Summary
The first end-to-end empirical evaluation of attack vectors targeting the MCP ecosystem. The authors identify four categories of attacks — Tool Poisoning Attacks, Puppet Attacks, Rug Pull Attacks, and Exploitation via Malicious External Resources — and evaluate feasibility by uploading malicious MCP servers to three widely used MCP aggregation platforms, following an upload → download → attack pipeline. A user study with 20 participants shows users struggle to identify malicious MCP servers.

## Key Contributions
- Identification and empirical validation of four MCP attack categories.
- Demonstration that current audit mechanisms on MCP aggregator platforms fail to catch malicious servers.
- User study (n=20) showing end users unknowingly install malicious MCP servers.
- Empirical demonstration of real-world harmful actions (private file access, device control, digital asset transfer) triggered via MCP attacks.
- Discussion of four key challenges facing the MCP security ecosystem.

## Relevance to Search Requirements
