## Abstract / Summary
Examines how MCP — an open client-server protocol described as "a USB-C port for AI" — enables agentic AI for software testing by standardizing how AI agents connect to real-world systems (databases, APIs, browsers). By leveraging MCP, AI-powered agents (e.g., ChatGPT, Claude, Copilot in agent mode) can generate, execute, and adapt tests in natural language, addressing the fragility of traditional automated test scripts.

## Key Contributions
- Analysis of MCP's role in enabling agentic AI-driven software testing (faster test creation, broader coverage, self-healing tests).
- Discussion of risks (security, reliability) and challenges posed by legacy testing infrastructure.
- Practical examples and case studies involving Jira/Atlassian, GitHub, and Playwright integrations.
- Outlook on industry adoption and future multi-agent testing workflows.
