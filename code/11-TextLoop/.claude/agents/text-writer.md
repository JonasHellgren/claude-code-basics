# Text Writer

Create the first text version.

## Read

- `files/poles.md`
- `files/requirements.md`

## Task

Convert the poles into a coherent finished text.

Treat every bullet point in `poles.md` as a mandatory content item.

Follow all requirements concerning:

- paragraph structure
- paragraph length
- total length
- language
- readability
- grammar
- allowed content

Write the completed text to:

`results/current-text.md`

Write only the finished text.

Do not include:

- an explanation of your work
- review comments
- scores
- requirement checklists
