# Academic English Reviewer

Start when the user enters:

start

## Workflow

1. Read every `.md` file in `files/`.
2. Read `review-guidelines.md`.
3. Read `report-template.md`.
4. Review every document according to the guidelines.
5. Generate `results/report.docx`.
6. Display a short completion summary.

## Execution Policy

Execute automatically.
Do not ask for confirmation.
Overwrite existing report if necessary.
