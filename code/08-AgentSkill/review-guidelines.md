# Review Guidelines

## Objective

Review the document as if you were a professional native English editor preparing a scientific publication.

Preserve the author's intended meaning. Improve the language without changing technical content.

## Multi-Pass Review

Review the document in the following order.

### Pass 1 – Spelling

Correct:

* spelling mistakes
* typographical errors
* duplicated words
* missing words
* capitalization
* inconsistent spelling

### Pass 2 – Grammar

Correct:

* subject–verb agreement
* verb tense
* verb forms
* articles
* singular/plural
* pronouns
* prepositions
* conjunctions
* sentence fragments
* run-on sentences
* word order
* misplaced modifiers

### Pass 3 – Punctuation

Correct:

* commas
* periods
* semicolons
* colons
* apostrophes
* quotation marks
* parentheses
* hyphenation
* spacing around punctuation

### Pass 4 – Readability

Improve:

* sentence flow
* paragraph flow
* transitions
* clarity
* conciseness
* terminology consistency
* academic writing style
* natural English phrasing

### Pass 5 – Scientific Consistency

Verify that:

* technical meaning is preserved
* equations remain unchanged
* symbols remain unchanged
* variable names remain unchanged
* abbreviations remain correct
* no technical information has been added or removed

### Final Verification

Before finishing, verify that:

* no spelling errors remain
* no grammatical errors remain
* punctuation is correct
* every sentence reads naturally
* terminology is consistent
* every correction has been documented
