# Report Template

Generate one DOCX report containing one section for each reviewed Markdown file.

## Section Layout

Filename.md

──────────────────────────────────────────────

## Original Text

Include the complete original text.

Bold **only** the exact words, phrases, or sentences that contain corrections.

Do not bold unchanged text.

## Corrected Text

Include the complete corrected text.

Never use bold formatting in this section.

## Changes

List every correction using the format:

* "<original>" → "<corrected>" (Reason)

Example:

* "secoond" → "second" (Spelling)
* "are" → "is" (Grammar – subject–verb agreement)

## Accepted Reasons

* Spelling
* Grammar – subject–verb agreement
* Grammar – article
* Grammar – verb tense
* Grammar – verb form
* Grammar – singular/plural
* Grammar – preposition
* Grammar – sentence structure
* Grammar – word order
* Punctuation
* Capitalization
* Word choice
* Readability
* Sentence flow
* Paragraph flow
* Academic style
* Clarity
* Conciseness
* Consistency
* Terminology consistency

## DOCX Formatting

* Document title: Academic English Review
* Heading 1 for each filename
* Heading 2 for Original Text, Corrected Text, and Changes
* Consistent fonts and spacing
* Bullet list for corrections
* Page break between document sections
