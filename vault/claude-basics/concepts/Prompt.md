
A **prompt** is the instruction given to the agent. It describes what the agent should do, what result is expected, and sometimes which rules or constraints must be followed. A prompt can be simple, such as `start`, or detailed, with input files, output formats, and quality requirements. In Claude Code, the prompt works together with the project instructions in `CLAUDE.md`. The prompt starts the task, while `CLAUDE.md` defines the broader behavior and workflow.
