A hook is an automatic reaction to a specific event in Claude Code. It follows the pattern “when something happens, perform an action,” such as running tests after code changes, formatting a file after it is written, blocking unsafe commands before execution, or updating a generated summary when new data is added. Unlike instructions in `CLAUDE.md`, which Claude is expected to follow, hooks are triggered by Claude Code itself when the configured event occurs, making them more predictable for repetitive automation.
