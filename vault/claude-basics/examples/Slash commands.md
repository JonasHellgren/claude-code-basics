**Slash commands** are reusable prompts that can be started with a command such as `/meeting` or `/review`. They automate common tasks, accept optional arguments, and help standardize workflows across projects. 

[[Examples]]

## Built in

placed in C:\Users\<name>\.claude\commands

## Example of customized



**Command name=init-project-folders.md**

`Initialize the current project by creating the standard folder structure.`

`Create the following folders if they do not already exist:`

- `results`
- `files`
- `.claude/agents`
- `.claude/commands`

`Do not overwrite or remove existing files or folders.`

`When finished, display a short summary showing:`

- `Folders created`
- `Folders that already existed`
