
In this project, the Consensus [[MCP]] server gives the agent access to scientific literature. The search topic and requirements are defined in `query.md`. When the user enters `start`, the agent reads the query, searches for relevant papers through Consensus, creates one Markdown file for each selected paper, and generates an index linking all results.

The workflow runs autonomously with minimal user interaction and can be reused for new research topics by changing `query.md`.
